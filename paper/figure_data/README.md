# Figure-data package

These files are the data hand-off for the four main-paper figure specifications. All values are copied from saved reports; no model was run for this package.

- Figure 1 is schematic only and has no data file.
- `figure2_features.json` contains the three-way audit, the criterion-passing exemplars, and literal top-activation snippets.
- `figure3_quantitative.json` contains the stability and concept-AUC anchors. It points to the canonical per-ID and per-intent CSVs needed for distributional panels.
- `figure4_interventions.json` contains swap specificity and the 200-example generation pilot with Wilson intervals.

Use the original CSVs referenced in the JSON files for any distributional plot; do not infer per-case values from the aggregate summaries.
