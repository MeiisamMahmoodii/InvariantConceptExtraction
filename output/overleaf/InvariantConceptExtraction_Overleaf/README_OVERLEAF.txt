OVERLEAF IMPORT

1. In Overleaf, choose New Project -> Upload Project.
2. Upload InvariantConceptExtraction_Overleaf.zip.
3. Overleaf should select main.tex automatically. If it does not, open Menu and set Main document to main.tex.
4. Use pdfLaTeX as the compiler.
5. Compile normally. The package includes the converged auxiliary and bibliography files so the two-column review line numbers begin in the correct margins. After deleting generated files or changing pagination, recompile until the line numbers stabilize.

The package contains the current paper sources, bibliography, ACL style files, converged auxiliary files, the four manuscript figures, and the verified PDF.
