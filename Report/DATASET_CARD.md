# Controlled C×S dataset card

## What C means

One concept is a capital-city record. Its fixed factors are `C_entity` (the capital city), `C_country` (the sovereign state), `C_continent`, and `C_language` (one official language).

## What S means

`S_family` changes only how the same four C factors are written: `declarative`, `question`, `paraphrase`, `formal`, and `structured`. Each concept has exactly one `v1` realization in every family. `declarative`, `question`, and `paraphrase` are `S_train`; `formal` and `structured` are held-out `S_test` families.

## Factual source and provenance

The source snapshot is `data/wikidata_capitals.json`, downloaded on 2026-08-25 from Wikidata SPARQL. The query selects sovereign states (`wd:Q3624078`) with their capital (`P36`), continent (`P30`), and official language (`P37`). Every dataset row records the source snapshot name, source entity/country IDs, a Wikidata provenance URL, and source name. No factual label was generated by an LLM.

## Generation and splits

Run `python code/generate_cs_dataset.py`. It uses fixed templates (`template-v1`) and seed `20260825`. The first 70 concepts are `C_train`, the next 15 are `C_val`, and the final 15 are `C_test`; a concept occurs in one C split only. The local source snapshot makes generation reproducible without another download.

## Validation

Run `python code/validate_dataset.py`. It fails on missing columns or values, inconsistent C factors, incomplete S families, duplicate texts, C-split leakage, S-split leakage, unexpected size, or empty coverage cells. The report is `Report/validation_report.json`.

## Known limitations

This is a small, template-based sandbox, not a broad natural-language corpus. A multilingual country contributes one official language per concept, and Wikidata can change after the saved snapshot date. The templates deliberately repeat all four factors so the task stays identical across S families.
